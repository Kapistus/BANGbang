Listed modifiers apply to their respective item classes.

Number of modifiers: Items have 0-3 modifiers, where 0 is the base item and 2 and 3 are exceptional
	             items that are more rare to come by. 
Rarity: Chance of a modifier to appear on an item in % out of 100.
Drop rate: The rate at which items drop from killed enemies and containers etc.


Normal enemies:  ( Regular bandits, mutants, humans)
Tough enemies: ( Veteran bandits, guards, soldiers, lesser monsters )
Elite enemies: ( Named characters, bosses, monsters )

WEAPONS:
--------

	if 0-1 module slots:
1: none
2: none

4: 1
5: 1
	if 0-2 module slots:
1: none
2: none
3: 1
4: 1
5: 2


Type of modifiers:
	
Rate of fire:  	+ 1-10% to rate of fire.
Reload speed:  	+ 1-10% to reload speed.
Accuracy:	+ 0.1-2.0% to accuracy. ( up to 99% )
Magazine size:	+ 10% - 20% to magazine size. ( rounded up )
Module slots:   + 1 or 2 module slots.



------
ARMOR:
------
Number of modifiers: ( if regular item, unique items have higher modifier rates )
	if 0-1 module slots:
		0 modifiers: 75%
		1 modifier:  25%
	if 0-2 module slots:
		0 modifiers: 70%
		1 modifier:  20%
		2 modifiers: 10%

Type of modifiers:


	If helm:
Armor rating: 	+ 0 - 1 to armor rating.
Module slot: 	+ 0 - 1 module slots.	
	If body armor:
Armor rating: 	+ 0.1 - 10.0% to armor rating. ( rounded up )
Module slots: 	+ 1 - 2 module slots.
Speed reduction:+ 0.1 - 2.0% to movement speed.
